# CEC2011: population 90, equal 150000-evaluation budgets

All 22 native CEC2011 problems, nine algorithms excluding Sep-CMA-ES, seeds 0/1/2.
Population 90 is supplied to every algorithm. Every trial stops at exactly
150,000 actual objective calls, including initialization, invalid candidates,
and any parent or selection calls made by an algorithm. A final generation may
be partial. Total planned work is 594 trials and 89.1 million objective calls.

GA-MPC uses fitness reuse and max_gen=None. Its stopping rule is exclusively the
objective-call counter. Other algorithms receive an iteration guard that cannot
be reached before the evaluation counter; CMA-ES target-fitness termination is
disabled. Evaluation-progress parameter schedules use the evaluation fraction.
PSO velocities start at zero, c1=c2=2, and common velocity limits/reflection are
retained. HPPSO uses eta=0.001 and corrected openness. T3 uses [0.6,0.9]. CMA-ES
uses the tested covariance/step-size safeguards. Objectives are not shifted.

```powershell
$env:PYTHONPATH='D:\hppso-git\.deps\cec2011;D:\hppso-git\src'
python -u -m experiments.cec2011_equal_budget --workers 2 --port 8772
```

On another machine: install the repository and minionpy==1.9.1 first.
The command resumes completed raw trials and rejects changed scientific sources
or settings. After a shutdown, verify that no worker remains before removing
the stale .shard-cec2011.lock file in this run's output folder.

Live progress: http://127.0.0.1:8772/.
Output: experiments/results/cec2011_pop90_fe150k.
Raw gzip trial records save actual counts, best solutions, traces, time and
non-finite candidate counts. Result-file writes retry transient Windows locks.
CSV snapshots use unique filenames in exports to avoid locked-file overwrites.
After every problem's 27 trials finish, comparison PNG/PDF curves are saved.
Curves show median and min–max over three seeds; ranges are not confidence
intervals. Final tables include mean/SD, minima, ranks and coverage audits.
Wilcoxon tables are generated if all 594 outcomes succeed. Incomplete blocks
are excluded from overall ranks. This is a fresh run; no earlier optimizer
results are reused. The localhost page stays available after completion.

The logarithmic-y renderer runs separately so plot changes do not alter the
frozen optimizer source or interrupt trials:

```powershell
python -u -m experiments.cec2011_log_curves --watch
```

It updates saved PNG/PDF curves after each problem completes. Strictly positive
values use a log y-axis; zeros or negative values use symmetric log with the
linear threshold stated on the axis. Raw objective values are unchanged.
Restart this renderer with the optimizer after a machine shutdown, or omit
--watch to redraw only currently finished problems. Reload the web page to
refresh images that were already displayed.
