# CEC2011: population 200, exactly 200000 evaluations per algorithm

All nine algorithms (excluding Sep-CMA-ES), all 22 problems, seeds 0–2.
Population is 200 for every algorithm. Each trial stops solely when its actual
objective counter reaches exactly 200,000 evaluations, including initialization,
non-finite candidate calls and all internal evaluations. There is no practical
iteration cap; GA-MPC explicitly uses max_gen=None. Iteration guards on the other
algorithms cannot stop before the evaluation counter. CMA-ES target-fitness
termination is disabled. Planned work: 594 trials, 118.8 million objective calls.

This is a fresh run of all algorithms, not a mixture of earlier iteration-stopped
results. PSO velocity initialization is zero; common c1/c2 and velocity/reflection
settings remain. HPPSO's openness and eta corrections, T3 bounds [0.6,0.9], the
stabilized CMA-ES implementation and GA-MPC fitness reuse are retained.

Raw results are saved after each trial, with transient Windows file-lock retries.
CSV snapshots use unique filenames. Every completed problem receives PNG/PDF
comparison curves with logarithmic x and logarithmic or symmetric-log y axes.
After all trials, tables show mean/SD, minima, mean-based ranks and actual
evaluation counts. Wilcoxon/Holm comparisons are generated if all trials succeed.
The exact counters are checked in the output audit. Three-seed min–max bands
are descriptive ranges, not confidence intervals. The command is resumable.
All 198 short population-200 problem/algorithm checks passed, including exact
stopping partway through a population.

from the displayed x coordinates. It hides initialization and the first
population's worth of updates. GA generations can have variable evaluation
counts, so this cutoff is defined by evaluations rather than native generation
boundaries. Best-so-far values still include previously found candidates. Raw
counts, the 200,000-call stopping rule and statistics are unchanged.
